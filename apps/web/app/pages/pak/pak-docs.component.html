Local server required

This page needs nwbt serve running locally to load game assets. Follow these steps:

  1. Clone the repo and copy .env.example → .env
  2. Set NW_GAME_LIVE to your New World install path
  3. Run the server:
./tools/bin/nwbt serve --texture-size 2048

Runs at http://localhost:8000 by default. Don't omit --texture-size 2048 or performance will suffer.
